Each round's output becomes the next round's input. The structure carries no preference for direction: the same loop drives runaway success or runaway collapse depending on which way it starts moving. "Virtuous cycle" and "vicious cycle" name one structure in two directions.

Examples across unrelated domains: a reputation that attracts better people who produce more success; a bank run (fear drives withdrawals, which make failure likelier, which drives more fear); publicity drawing copycats whose activity attracts more attention, which brings more publicity; technical debt that slows every change and so breeds more shortcuts.

No reinforcing loop runs forever. It doesn't contain its own limit; something else in the system, a balancing loop, eventually does (see Limits to Growth).
