Tripling each round gives 10, 30, 90, 270. The absolute change goes 20, 60, 180. Nothing about the loop changes between rounds; only the base the same multiplier acts on grows. By the time exponential growth or collapse is obvious to the eye, the loop has already run several rounds, and the most consequential intervention decisions were the ones available when the curve still looked flat.

Faster feedback channels (a live rating instead of word of mouth) shorten each round, so the same structure gives even less warning.
