Four parts, worth naming every time:

1. **Current state**: the quantity being governed (room temperature, regulatory attention, headcount).
2. **Reference point** (goal): the value the loop steers toward.
3. **Gap**: the difference between them, the only thing the loop responds to.
4. **Corrective action**, sized to the gap: the furnace firing, the operating tempo dropping.

The action moves the state, the state changes the gap, the gap sets the next action.

**Seeking and defending are one mechanism.** Once at its goal the loop doesn't switch off; any disturbance reopens the gap and draws a correction. That's why a change that moves the state without moving the reference point tends to come undone: the loop treats it as a disturbance.

**It seeks its goal but never sets it.** The reference point comes from outside the loop. The loop defends a sensible goal and a foolish one with equal diligence, so the useful question is rarely "is it working?" (it almost always is) but "what is it working toward, and who or what put that there?"

Many balancing loops have no goal anyone wrote down, only a limit that acts as one: a fixed training staff implies a headcount it can train well; below it the loop barely registers, above it the brake presses harder.

Every reinforcing spiral eventually meets a balancing loop, either already active or waiting for the spiral to cross its threshold.
