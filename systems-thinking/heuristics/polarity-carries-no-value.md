---
id: polarity-carries-no-value
type: heuristic
title: Reinforcing isn't good, balancing isn't bad
summary: Loop type says how a loop behaves, not whether that behavior is welcome; judge each loop by the direction it is running and the goal it defends.
chapters: [6, 7, 8]
when: Someone labels a loop "virtuous" or "the brake" and stops analyzing.
then: Ask which direction the reinforcing loop is running now and what would reverse it, or what goal the balancing loop defends and who set it.
links:
  related: [reinforcing-loop, balancing-loop]
---

A reinforcing loop can compound success or collapse with the same structure. A balancing loop can stabilize something worth keeping or stubbornly defend a status quo nobody wants. The value judgment has to come from the situation, not the label.
