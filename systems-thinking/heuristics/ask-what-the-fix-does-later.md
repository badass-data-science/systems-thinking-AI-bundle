type: heuristic
title: Ask what a fix does a few rounds out
summary: Before reaching for a fix that works now, ask what it will do after it has been applied several times, because a fix that works now and fails later gets reached for again.
chapters: [11, 22]
when: A fix has worked before and is about to be applied again, or a new fix promises immediate relief.
then: Trace the fix's side effects through to the problem it relieves, with their delays. If any side effect feeds the problem or erodes a better fix, use the quick fix only as a bridge while working on the root cause.
links:
  diagnoses: [fixes-that-fail, shifting-the-burden]
  related: [second-order-effects]
series: [unintended-consequences]
---

A fix that failed instantly would be abandoned instantly. One that works now and fails later looks like the obviously right call every time, which is what makes Fixes That Fail addictive.
