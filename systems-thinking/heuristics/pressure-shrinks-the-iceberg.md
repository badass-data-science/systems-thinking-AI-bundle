id: pressure-shrinks-the-iceberg

title: Pressure keeps analysis at the event level
summary: The pull to react to the event and move on is strongest when stakes are highest, so the deeper bands need to be asked for deliberately under pressure.
chapters: [5]
when: An incident is in progress, a deadline is close, or someone senior wants an answer now.
then: "Handle the event, then ask one more question before closing it: what in the way this system is arranged makes this the kind of thing that happens here?"
links:
  related: [iceberg-model, iceberg-analysis]
---

Descending to the structure band doesn't require heroics, only one deliberate extra question after the obvious one has been answered. Schedule that question if it can't be asked in the moment; don't let the incident close without it.
