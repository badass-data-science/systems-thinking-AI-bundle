title: A good historical fit is easy to manufacture
summary: Any model with guessed parameters can be tuned to reproduce the past, so a good fit proves only that the model can be tuned, not that its mechanisms are right.
chapters: [18]
when: A model is presented as trustworthy because it matches history.
then: Ask which parameters were adjusted to get the fit, and check the structure link by link separately.
links:
  related: [structural-and-behavioral-validity, confirmation-bias]
series: [model-validation]
---

Wrong mechanisms that happen to fit the past fail under new conditions, which are the only conditions anyone builds a model to ask about. This is one of the most common ways a model earns trust it hasn't earned.
