## Situation

Only a few sites in a region meet all of an industry's criteria (stable, secluded, attractive). Three operations race to claim one each, then overbuild, because a bigger site looks like a bigger win and a rival's overbuilding is what each is racing against.

## Analysis

Each operation: a reinforcing overbuild → gains → overbuild loop, and a balancing loop through the shared stock of regional site viability (one minus), acting with a delay. Collective overbuilding degrades the stock (geological instability) and a suspicious cluster of purchases draws surveillance that burns every operation's cover. Every operation can correctly foresee this and still rationally overbuild, because holding back alone just hands the best sites to the others.

## Lesson

Winning the race and losing the resource can be the same outcome. No single operation can fix it; only rules every user agrees to, can see kept and can enforce would. With no such governance, the book leaves this case unsolved.
